# First Steps Website

A simple static website for a co-sponsored initiative helping people experiencing homelessness obtain legal documentation, connect to resources, and become independent.

## Files

- `index.html` — homepage structure and content
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation and contact form interactions

## Usage

Open `index.html` in your browser to view the site locally.

To add your own logo, replace `logo.svg` with your logo file in the project folder and update the `src` path in `index.html` if needed.

For development, you can also use a local web server such as:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
